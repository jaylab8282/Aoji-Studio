# 픽셀 캐릭터 규격

에이전트 1명 = 캐릭터 1개. 좌표는 격자 칸 단위이고, 화면에서는 정수배로 확대한다. 확대할 때 보간을 끄고 픽셀을 살린다(`shape-rendering: crispEdges`, `image-rendering: pixelated`).

## 동작 표현

| 동작 | 조건 (hook 이벤트) | 표현 |
|---|---|---|
| 타이핑 | Edit, Write | 말풍선 `타이핑 · <도구>`, 모니터 화면 밝은 상태색 |
| 읽기 | Read, Grep, Glob | 말풍선 `읽기 · <도구>` |
| 권한 요청 | 권한 요청·입력 대기 | 주황 채움 말풍선 `권한 요청`, 셔츠·화면 주황 |
| 대기 | 종료 이벤트 후 | 회색 말풍선 `대기`, 화면 꺼짐색 |
| 그 밖의 도구 | Bash, WebFetch 등 | 말풍선에 도구 이름 그대로 (표현 방식 미정 — 요구사항 OQ-F6) |

## 배치

- 팀장이 첫 자리, 나머지는 name 오름차순.
- 선택된 캐릭터 칸은 `state/running` 테두리 + 옅은 초록 배경.
- 서브에이전트는 부모 아래·옆에 작은 캐릭터로 두고 상태 글자에 `부모 <name>`을 적는다.
- 빈 자리는 점선 테두리 칸에 `빈 자리`.

## 애니메이션

- v1에서는 움직이는 애니메이션을 넣지 않는다. 상태가 바뀔 때 색 전환만 200ms 이내로 부드럽게 한다.
- 실행 중 표시등의 발광은 정적이다. 깜빡이지 않는다.
