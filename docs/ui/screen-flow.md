# 화면 이동

```text
앱 접속 127.0.0.1:<포트>
        │
        ▼
      01 홈 ──(워크플로우 카드 / 사이드 탭)──▶ 02 층 뷰 ──(층 '상세 →')──▶ 03 워크플로우 상세
        ▲                                        │                              │
        └──────────(브레드크럼 '홈')──────────────┴──────(브레드크럼)────────────┘
```

| 출발 | 동작 | 도착 |
|---|---|---|
| 01 | 워크플로우 카드, 사이드 탭 `에이전트 워크플로우` | 02 |
| 01·02 | 워크플로우 0개 카드의 `워크플로우 추가` | 05 왼쪽 |
| 02 | 층 `상세 →` | 03 |
| 02 | `+ 워크플로우 추가` | 05 왼쪽 |
| 02 | 층 `가져오기`, `워크플로우 밖 에이전트 N · 가져오기` | 05 오른쪽 |
| 02 | `+ 에이전트 만들기`, 층 `+ 만들기` | 06 |
| 02 | `Claude 열기 · 기본 세션` | 맥북 터미널 (화면 이동 없음) |
| 03 | `팀장 호출 · 터미널 열기` | 맥북 터미널 (화면 이동 없음) |
| 03 | `정의 수정`, `제거` | 06 |
| 03 | 브레드크럼 | 01 또는 02 |
| 05 | `+ 새로 만들기` | 06 |
| 06 | `저장` | 02 (파일이 밖에서 바뀌었으면 충돌 창) |
| 06 | `워크플로우에서 제거` | 제거 확인 창 |
| 사이드 탭 `설정`, 04-5 `설정 열기` | | 07 |

- 04 상태 화면은 독립 화면이 아니라 01·02·03·07 안에서 나타나는 상태다.
- 웹에서 에이전트를 실행하거나 작업을 지시하는 이동은 없다.
