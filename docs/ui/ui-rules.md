# UI 규칙

`design-tokens.md`의 값만 쓴다. 화면에 색·글꼴·간격 값을 직접 적지 않는다.

## 1. 에이전트 상태 표시

- 상태는 세 가지다: `작업 중`(running) · `권한·입력 대기`(waiting) · `대기`(idle).
- **색만으로 구분하지 않는다.** 캐릭터, 칩, 표 어디에서든 상태 글자를 함께 표시한다. 대기 색은 배경과 대비가 낮다.
- 상태 점·사각형은 9~10px, 모서리 3px. 실행 중 표시등에만 발광을 준다.
- 워크플로우 칩: 실행 중이면 `실행 중 [N]명`(running), 권한 대기가 있으면 `권한 대기 [N]명`(waiting), 둘 다 없으면 `모두 대기`(중립 배경 `bg/selected`).

## 2. 버튼

| 종류 | 표현 | 예 |
|---|---|---|
| 주 동작 | `state/running` 배경 + `text/on-accent` 글자 | 정의 수정, 에이전트 워크플로우 열기 |
| 터미널 열기 | `state/running` 테두리 + `running-soft` 배경 + 초록 글자 + 터미널 아이콘 | 팀장 호출 |
| 보조 | `border/strong` 테두리 + `bg/soft` 배경 | Claude 열기 · 기본 세션, 다시 읽기 |
| 추가 | `border/dashed` 점선 테두리 | + 에이전트 만들기, + 워크플로우 추가 |
| 위험 | `state/danger-border` 테두리 + `danger-soft` 배경 + `state/danger` 글자 | 제거 |
| 비활성 | 점선 테두리 + `text/faint` 글자 + 옆에 이유 한 줄 | 팀장 없음, 도우미 미설치 |

- 눌러도 아무 일이 없는 활성 버튼을 만들지 않는다. 조건이 안 되면 비활성 + 이유다.

## 3. 터미널 열기

- 02 헤더: `Claude 열기 · 기본 세션` 하나. `cd "<프로젝트 폴더>" && claude`
- 03 헤더 오른쪽: `팀장 호출 · 터미널 열기`. `cd "<프로젝트 폴더>" && claude --agent <팀장 name>`
- 02에는 팀장 목록을 두지 않는다. 팀장 세션은 그 워크플로우 상세에서만 연다.
- 팀장이 없으면 03의 버튼은 비활성이고 `팀장 없음`을 함께 표시한다.
- 열기 도우미가 없으면 누를 때 미설치 안내와 명령 복사를 보여준다.

## 4. 목록·필터

- 층 필터는 칩 나열이 아니라 **검색 입력창 + 층 선택 드롭다운**이다. 드롭다운 첫 항목은 `전체 층 ([N]개)`.
- 워크플로우 수에 상한이 없으므로, 개수가 늘어도 상단 바가 줄바꿈으로 무너지지 않아야 한다.
- 에이전트 name이 12자를 넘으면 말줄임하고 마우스를 올리면 전체를 보여준다.

## 5. 화면 상태 (모든 화면 공통)

| 상태 | 표현 |
|---|---|
| 로딩 | 숫자·이름 자리에 스켈레톤. `0`을 먼저 보여주지 않는다 |
| 빈 상태 | 무엇이 없는지 + 다음 행동 버튼 한 개 (예: 워크플로우 0개 → `워크플로우 추가`) |
| 에러 | 무엇을 못 했는지 + 원인 + 복구 버튼(`다시 읽기`, `설정 열기`) |
| 실시간 연결 끊김 | 화면 상단 배너 `실시간 연결이 끊겼습니다 · N초 후 재연결` + `지금 재연결`. 마지막 갱신 시각 기준 화면 유지 |
| 수집 중단 | 상세 화면 배너 + 마지막 수신 시각. 캐릭터는 모두 대기색 |

## 6. 민감 정보

- 이벤트 요약의 token·key·password 등은 `••••••••`로 가린다.
- 가리기 전 원문은 화면 어디에도 보이지 않는다. 마우스 오버로도 보여주지 않는다.

## 7. 화면별 고정 사항

| 화면 | 고정 사항 |
|---|---|
| 01 홈 | KPI 4개(실행 중/에이전트 수/스킬 수/수집 상태) → 상태 막대 → 대표 워크플로우 3개 → 실시간 이벤트 표 순서 |
| 02 층 뷰 | 상단 헤더 → 요약·범례·검색 바 → 로비 → 층 그리드(3열, 인원 많은 층은 가로 3칸 차지) |
| 03 상세 | 왼쪽 오피스 그리드(3열) + 오른쪽 360px 패널. 패널 기본 선택은 팀장 |
| 04·05·06·07 | 와이어프레임 구성 유지 + 이 문서의 토큰·규칙 적용 |

## 8. 접근성

- 본문 대비는 배경 대비 4.5:1 이상. `text/faint`는 보조 정보에만 쓴다.
- 상태는 색 + 글자, 아이콘 버튼에는 `aria-label`을 둔다.
- 클릭 가능한 영역은 최소 34px 높이.
