# 디자인 토큰

다크 단일 테마다. 라이트 테마는 이번 범위에 없다.

|---|---|---|
| `bg/page` | `#0E1320` | 화면 바탕 |

| `bg/card` | `#161D2C` | 카드, 패널 |

## 글꼴

| 용도 | 값 |
|---|---|
| 본문 | IBM Plex Sans KR |
| 고정폭 | IBM Plex Mono — 경로, 명령, 시각, 에이전트 name, 수치 |
| 크기 | 화면 제목 24~26 / 섹션 제목 14~15 / 본문 12.5~13 / 보조 11.5~12 / 최소 10 |
| 굵기 | 제목 700 / 강조 600 / 본문 400 |

## 간격·모서리

| 항목 | 값 |
|---|---|
| 화면 좌우 여백 | 32px |
| 카드 안 여백 | 16~18px |
| 요소 사이 | 6 / 8 / 10 / 14 / 16 / 18px |
| 모서리 | 버튼·입력 9px · 카드 12px · 칩 10px · 배지 6px |
| 사이드바 폭 | 248px |
| 헤더 높이 | 64px |
| 버튼 높이 | 주 40~44px · 보조 34~36px |
| 오른쪽 상세 패널 폭 | 360px |

## 그림자·발광

- 실행 중 표시등에만 발광을 쓴다: `0 0 8~10px rgba(61,214,140,0.8)`
- 카드에는 그림자를 쓰지 않는다. 경계는 테두리로만 만든다.
