  - **변경 전 코드는 `expect.poll`이 아니라 web-first 단언이었다**는 것이 핵이다. ADR-50 A가 인용한 `[100, 250, 500, 1000]`은 `expect.poll` 격자이고 변경 **전** 코드에 해당하지 않는다 → "실여유 ~150ms"는 틀렸고 실제는 **≈850ms**였다. T-FIX-11이 회복한 여유는 ~950ms가 아니라 **약 75ms**다
  - **팀장도 틀렸다(기록해 둔다)**: 팀장이 세션 중 사용자에게 "실여유 150ms → 971ms"로 보고했는데 그 전제가 ADR-50 A였다. 리뷰어가 뒤집었고 팀장이 사용자에게 **즉시 정정 보고했다**

  - **그래도 T-FIX-11은 되돌리지 않는다**: 25ms < 100ms는 단조 개선이고 비용 0이며, 본체 이득은 **실패 문구 2종 분리**(미반영 = 기능 결함 / 초과 = 실측 ms)와 **실측 ms 기준선**이다. 이 기준선이 A-25의 재판정을 닫을 유일한 도구다. 틀린 것은 ADR 본문의 정량 서술이고 `ui-helpers.ts` 주석은 새 코드 기준으로 정확하다 → 코드 수정 지시 0건
