## 계약 (api-spec.yaml)
- `POST /api/agents` — 경로·메서드·본문(`name/description/model/workflow/role/toolsMode/tools?/body`) 일치. `toolsMode:"inherit"`일 때 `tools` 키를 아예 보내지 않는다(스펙의 "explicit일 때 1개 이상"과 정합).
- `GET /api/agents/{name}` — `encodeURIComponent` 적용. 404 `AGENT_NOT_FOUND` / 409 `UNEDITABLE` 분기 일치.
- `PUT /api/agents/{name}` — `expectedRevision` = GET의 `revision`, `force`는 덮어쓰기일 때만 `true`로 붙인다. 409 `REVISION_CONFLICT`(→06-5) / `AGENT_BUSY`(→폼 상단) / `FILE_GONE`(→폼 에러) / `LEAD_EXISTS`(→역할 옆) 4종 모두 처리.
- `DELETE /api/agents/{name}` — 200 `{trashPath, removedFromWorkflow}` 타입 일치, 404/409/500 분기 일치.
- `ApiErrorCode` 열거는 기존 `api/types.ts` 그대로 쓰고 새 코드를 만들지 않았다. **계약에 없는 필드를 가정한 곳 없음.**

## conventions

- `any`·`String(error)` 0건. `location.state`는 `unknown` → 좁히기.
- 토큰 밖 임의 수치·색상 0건.
- 지연 값: `AGENT_CREATED_NOTICE_MS = 8000` — ui-spec SCR-06 "8초" 명시값, 이름 있는 코드 상수, 테스트가 `toBe(8000)`으로 고정 ✔ (conventions §7 MUST, ADR-34).
- 팝업 폭: 컴포넌트에서 `max-w-*` 직접 지정 0건 ✔ (ADR-40).
- 컴포넌트 파일 200줄 SHOULD: 최대 `AgentFormFields.tsx` 175줄 ✔.
- 미완성 코드(`TODO`/`FIXME`/`XXX`/`lorem`/`TBD`/빈 본문/운영 Mock) **0건**. 죽은 분기는 `submit()`의 `detail === null` 방어 한 곳뿐이며 도달 불가·무해하다.
